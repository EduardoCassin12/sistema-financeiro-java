# 💰 Sistema Financeiro

Sistema de gestão financeira desenvolvido em **Java**, criado como projeto prático para acompanhar minha evolução no desenvolvimento Back-end.

O projeto será desenvolvido de forma incremental, começando com **Java e Programação Orientada a Objetos** e evoluindo posteriormente para uma aplicação completa utilizando **Spring Boot, PostgreSQL, API REST, autenticação, testes e Docker**.

---

## 🎯 Objetivo

Criar um sistema capaz de auxiliar no controle financeiro, permitindo o gerenciamento de:

- 💰 Receitas
- 💸 Despesas
- 🏦 Contas
- 🏷️ Categorias
- 📊 Saldo
- 📅 Transações
- 📈 Relatórios financeiros

O principal objetivo também é utilizar o projeto para colocar em prática os conhecimentos adquiridos durante meus estudos de **Java e desenvolvimento Back-end**.
